# Balíček FC ⚽

3D fotbalová hra pro kluky: rozbalování balíčků s kartičkami hráčů, sbírka, tým se střídáním, liga a pohár.

**Hrát:** https://zaoo-star.github.io/BalicekFC/balicek-fc.html

Jeden HTML soubor (three.js z CDN), postup se ukládá v prohlížeči. Instalovatelné jako appka (PWA).
Při každé aktualizaci zvyš verzi cache v `sw.js` (`balicekfc-v1` → `v2` …).
